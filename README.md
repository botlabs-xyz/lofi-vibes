## About

Lofi Vibes is a free-first Discord live radio bot for station playback, lo-fi listening, 24/7 radio mode, listener profiles, and server-level radio settings.

Lofi Vibes is **free-first**. Normal bot features are available without a paid unlock.

## Features

- Live radio station playback
- Preset station dropdown with `/station`
- 24/7 reconnect and recovery mode
- Listener profile cards with level, XP, listening time, and favorite station
- Server-level settings with `/server-profile`
- Station submission review flow with `/submit-station`
- Free-first supporter recognition

## Lofi Vibes+

Lofi Vibes+ is an **optional supporter membership**.

It does **not** unlock normal bot features. It supports hosting, uptime, development, bug fixes, and future improvements for everyone.

Supporter benefits:

- Supporter role in the official support server
- Community recognition
- Helps keep the bot online and maintained
