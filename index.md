## Overview

**Lofi Vibes** streams relaxing lo-fi music directly into Discord voice channels. It is designed for communities that want simple, always-friendly background audio for studying, co-working, and laid-back hangouts.

## Features

- Relaxing lo-fi radio streams
- Background playback for study and chill servers
- Minimal setup for quick voice-channel use
- Lightweight command surface focused on listening
- Great fit for all-day ambient server audio

## Quick Start

1. Invite the bot to your server.
2. Join the voice channel where you want the stream to play.
3. Start the radio stream using the bot's playback or start command.
4. Use the help command if you want to browse any available listening modes.

## Commands

Lofi Vibes focuses on a small set of command categories:

- Start or resume a stream
- Stop or disconnect from voice
- Basic playback or station controls
- Help and support links

If your deployment exposes additional station or mood commands, the in-bot help menu is the best place to confirm them.

## Required Permissions

- View Channels
- Connect
- Speak
- Send Messages
- Embed Links
- Read Message History
- Use Slash Commands

## Troubleshooting

- If the bot joins but plays nothing, check the voice permissions and any host-side playback service dependencies.
- If the stream drops, retry once and confirm the voice channel or host connection is still healthy.
- If commands are not responding, confirm slash commands are available in the server and the bot can post in the channel.
- If you are using a very restrictive permission setup, test in a simple voice channel first.

## FAQ

### Is Lofi Vibes built for playlists or radio-style listening?

Its positioning is radio-style background listening rather than deep queue management.

### Is it a good fit for study servers?

Yes. That is one of the clearest intended use cases described for the bot.

### Where should I check for the latest controls?

Use the in-bot help output for the current deployment, especially if listening modes change over time.
