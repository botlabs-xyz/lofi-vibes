## Commands

| Command | Description | Typical Use |
| --- | --- | --- |
| `/start` | Starts the lo-fi stream in your current voice channel. | Begin listening session |
| `/play` | Starts or resumes playback where supported by deployment. | Quick restart |
| `/stop` | Stops active playback. | End session |
| `/disconnect` | Disconnects bot from voice channel. | Cleanup |
| `/help` | Shows help and available controls. | Discover commands |
| `/support` | Returns support server link. | Get help |

> Exact command names can vary by deployment build; use `/help` in your server as source of truth.
